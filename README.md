# Procedural Arcade Data-Synth Engine

A retro-styled arcade game built in Python using Pygame-CS and NumPy. Dodge obstacles collect coins, upgrade your stats in the shop, and listen as you movement coordinates and game actions dynamically synthesize raw mathematical audio waves in real time!


 ## Cool Features <3

- Custom Arcade Game Loop
- Real-Time Digital Signal Precessing
- Data-Driven Audio
- In-Game Economy & Shop
- Cool, Beautiful Particle Effects

## Controls

S - Launch engine

W, A, S, D (or Arrow Keys) - Move player and trigger live audio arpeggios

P - Open/Close the upgrade shop menu

1 - Purchase Speed Boost

2 - Purchase Size Expansion 

Q - Wuit game

R - Reboot core system after a game over
